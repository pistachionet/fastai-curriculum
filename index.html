Connect your token, owner only

This is a single-user course log for the repo owner. A token only works here if it belongs to an account that already has write access to this repo, which is just you unless you have added someone as a collaborator on GitHub. Anyone else's token will connect but every submit will fail.

  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories, then pick this one repo.
  3. Permissions: Contents set to Read and write. Nothing else.
  4. Set an expiry you are comfortable with, generate, and paste it below.

The token stays in this browser's local storage on your machine and is sent only to api.github.com. Scoped to one repo with contents access, the worst case if it leaks is someone writing to your notes repo. Anyone can read your notes either way, the repo is public. Without a token you can still read this page, you just cannot submit from it.
